# Screenshots

Drop the real screenshots in here with these exact filenames — `index.html`
already references them, with a graceful placeholder shown until each one
exists.

| Filename | Used for | Suggested shape |
|---|---|---|
| `screenshot-web.png` | Web app (vault.keeperpass.com) | Wide, e.g. 2400×1500 |
| `screenshot-extension.png` | Browser extension popup | Narrow, matches the real popup — 400×600 |
| `screenshot-mobile.png` | Mobile view | Tall, e.g. 750×1624 |
